# Atualização profissional — H&S Achadinhos

1. Execute `supabase/migrations/002_professional_redesign.sql` no SQL Editor do Supabase.
2. Substitua os arquivos antigos do repositório pelos arquivos desta versão.
3. No terminal do Codespaces, execute:

```bash
npm install next@15
git add .
git commit -m "Redesign profissional H&S Achadinhos"
git push
```

4. Aguarde o novo deploy da Vercel ficar `Ready`.
5. Entre em `/admin/configuracoes` para personalizar logo, imagem principal, cores, textos e redes sociais.
