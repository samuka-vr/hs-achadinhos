# H&S Achadinhos V7.2 — ações em massa

## Novidades
- Checkbox em cada produto.
- Botão para selecionar/desmarcar todos os produtos exibidos.
- Publicar todos os selecionados de uma vez.
- Mover selecionados para rascunho.
- Excluir selecionados com confirmação.
- Contador de itens selecionados.
- Ações adaptadas para celular.
