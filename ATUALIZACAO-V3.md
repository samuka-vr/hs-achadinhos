# Atualização V3 — interface limpa

## 1. Atualizar o banco
No Supabase, abra **SQL Editor → New query**, cole todo o conteúdo de:

`supabase/migrations/003_clean_experience.sql`

Depois toque em **Run**.

## 2. Atualizar o código
Substitua os arquivos do projeto pelos desta versão e envie ao GitHub.
A Vercel fará o novo deploy automaticamente.

## O que foi alterado
- visual público mais limpo;
- carrossel automático de produtos em ordem aleatória;
- categorias circulares com imagem ou emoji;
- galeria com várias imagens por produto;
- painel simplificado e reorganizado;
- controles para mostrar ou esconder seções;
- upload de logo, favicon, capas, galeria e imagens de categorias;
- textos padrão mais naturais;
- nova paleta coral, branco e cinza claro.
